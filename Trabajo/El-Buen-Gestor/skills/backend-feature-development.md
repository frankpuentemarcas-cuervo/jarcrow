# 🚀 Backend Feature Development

Orquestador end-to-end de desarrollo de features: desde requirements hasta deployment.

## Cuándo usar
- Coordinar delivery completo de una feature
- Cambios multi-servicio con deploy y monitoreo
- Alinear scope, riesgos y métricas de éxito

## Fases
1. **Discovery**: Business analysis → Architecture design → Risk assessment
2. **Implementation**: Backend → Frontend → Data pipeline
3. **Testing**: Unit/Integration/E2E → Security → Performance
4. **Deployment**: CI/CD → Feature flags → Monitoring → Docs

## Metodologías
- Traditional | TDD | BDD | DDD

## Complejidad
- Simple (1-2d) | Medium (3-5d) | Complex (1-2w) | Epic (2w+)
