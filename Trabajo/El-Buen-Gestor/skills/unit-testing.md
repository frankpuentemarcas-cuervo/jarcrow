# 🧪 Unit Testing — Test Generator

Generador automático de tests unitarios multi-lenguaje con cobertura de edge cases.

## Cuándo usar
- Necesitas tests para código existente
- Quieres estructura de tests consistente
- Necesitas mocks, fixtures y edge-case validation

## Frameworks soportados
| Lenguaje | Framework |
|---|---|
| Python | pytest |
| JavaScript/TypeScript | Jest |
| Java | JUnit |
| Go | testing |

## Capacidades
- Análisis de código → generación automática de tests
- Happy path + edge cases + error handling
- Mock generation para dependencias externas
- Coverage analysis y gap detection
- React component tests (Testing Library)
