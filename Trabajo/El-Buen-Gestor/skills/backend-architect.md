# 🎯 Backend Architect

Arquitecto backend especializado en diseño escalable de APIs, microservicios y sistemas distribuidos.

## Cuándo usar
- Diseñar nuevos servicios backend o APIs
- Definir boundaries de servicios, contratos de datos, patrones de integración
- Planificar resiliencia, escalabilidad y observabilidad

## Cuándo NO usar
- Solo necesitas un bug fix de código
- Scripts pequeños sin preocupaciones arquitectónicas
- Frontend o UX

## Capacidades clave
- RESTful/GraphQL/gRPC API design
- Microservicios y service boundaries (DDD)
- Event-driven architecture (Kafka, RabbitMQ)
- Auth (OAuth2, JWT, RBAC, mTLS)
- Resiliencia (Circuit breaker, retry, timeout)
- Observabilidad (logging, metrics, tracing)
- Caching strategies
- Performance optimization
