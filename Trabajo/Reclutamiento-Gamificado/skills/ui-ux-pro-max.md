# 🎨✨ UI/UX Pro Max

Toolkit de inteligencia de diseño con bases de datos buscables de estilos UI, paletas de color, tipografías, charts y UX guidelines.

## Cuándo usar
- Buscar estilos UI (glassmorphism, minimalism, brutalism, etc.)
- Encontrar paletas de color por tipo de producto
- Buscar font pairings con Google Fonts
- Tipos de charts y librerías recomendadas
- Best practices UX y anti-patterns

## Dominios de búsqueda
| Dominio | Búsqueda |
|---|---|
| `product` | Recomendaciones por tipo (SaaS, e-commerce, portfolio) |
| `style` | Estilos UI + AI prompts + CSS keywords |
| `typography` | Font pairings con imports de Google Fonts |
| `color` | Paletas por tipo de producto |
| `landing` | Estructura de página y estrategias CTA |
| `chart` | Tipos de charts y librerías |
| `ux` | Best practices y anti-patterns |

## Stacks soportados
html-tailwind, react, nextjs, astro, vue, nuxtjs, nuxt-ui, svelte, swiftui, react-native, flutter, shadcn, jetpack-compose

## Comando de búsqueda
```bash
python3 src/ui-ux-pro-max/scripts/search.py "<query>" --domain <domain> --stack <stack>
```
